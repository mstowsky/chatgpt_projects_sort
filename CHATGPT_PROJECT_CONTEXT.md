# PROJECT CONTEXT

## 1. PROJECT

**Name:** Python-проект автоматизации ChatGPT через Playwright

**Description:**  
Python-проект для автоматизации действий в ChatGPT с помощью Playwright.

**Repository:** [https://github.com/mstowsky/chatgpt_projects_sort](https://github.com/mstowsky/chatgpt_projects_sort)

**Main branch:** main

## 3. ARCHITECTURE

Проект использует архитектуру Page Object Model.

Структура:
main.py - точка входа, запуск программы, верхнеуровневые бизнес-действия
browser.py - управление окном браузера через playwright
locators.py - локаторы элементов интерфейса
page_actions.py - низкоуровневые универсальные действия с элементами
tests.py - временное место для наших первых тестов. Потом тестовые методы отсюда будем переносить/превращать в рабочую логику.
pages/chatgpt_page.py - Page Object конкретной страницы ChatGPT

Подключение браузера выполняется через Playwright по CDP.
Используется порт: 127.0.0.1:9222

Подробный код находится в GitHub. Не дублировать его здесь.

## 5. WORKING RULES

При работе с проектом:
1. Сначала изучить актуальный код в GitHub.
2. Не предполагать устройство функций/файлов, если его можно проверить в репозитории.
3. Сохранять существующую архитектуру, если нет причины её менять.
4. Для небольших изменений показывать только изменяемые функции/фрагменты.
5. Перед существенным рефакторингом объяснять, зачем он нужен.
6. Если обнаружена проблема, не относящаяся к текущей задаче, указать её отдельно, но не исправлять самовольно.
7. Если для решения задачи не хватает информации — сначала указать, чего именно не хватает.
8. Не усложнять код ради более "красивого" решения, если простой Python-код уже решает задачу.
9. При работе с Chrome сохранять возможность подключения к существующему экземпляру через CDP.
10. После существенных изменений проверять работу сначала на конкретном небольшом сценарии, а затем расширять функциональность.
11. При добавлении нового действия по возможности сначала реализовать его как отдельный метод Page Object, затем добавить соответствующий тест, а уже затем переносить в реальный код работающей программы.
12. При добавлении нескольких print'ов подряд не добавляй между ними пустые строки в коде.
